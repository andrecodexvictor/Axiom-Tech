# Glossary

- **Agentic RAG:** Retrieval-augmented generation controlled by a graph of routing, retrieval, grading, rewrite, and synthesis nodes.
- **ChromaDB:** Local persistent vector store selected for the V3 default profile.
- **Grounded:** A response whose factual claims are supported by returned internal or verified external citations.
- **NIM:** NVIDIA inference endpoint used by the optional hosted model gateway.
- **Rewrite:** A bounded graph attempt to reformulate a question when retrieved chunks are not relevant.
- **SEV:** Severity level used by incident-response documentation.
- **Specialist:** Domain handler for HR, legal, engineering, repository/API, or explicit web research.
- **Web allowlist:** Configured host/subdomain set that limits external technical research and prevents arbitrary URL fetching.
